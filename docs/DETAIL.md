# TikTok 视频本地化流水线

左侧栏「视频本地化」入口打开一个批处理面板：粘贴一批 TikTok 链接（或本地视频路径），插件按流水线逐条产出可直接发布的成品。面板之外的同一套操作也注册为 `tiktok_localizer` 工具，方便在对话里直接驱动。

## 每条视频做什么

0. **无字幕的片子**：画面 OCR 找不到足够字幕（覆盖 <15% 或不足 3 条）时，该条会在面板标「⚠ 无画面字幕」，不会用口播硬生成字幕。
1. **取片**：按 `yt-dlp → tikwm` 依次尝试下载无水印 mp4（每条失败原因都会记录）；也接受本地文件或包含视频的目录。若本机 7890 端口有代理（如 FlClash），自动带上，无需额外配置。
2. **画面 OCR**：每 0.25 秒抽帧，用 macOS Vision 识别画面外文（默认日语／韩语／英语），按文本相似度聚成带时间轴的事件。
3. **人声 ASR（可选）**：默认关闭（`asrMode: ocr`）。改成 `auto` 才会用 faster-whisper 转写口播，且与 OCR 文本一致时以 OCR 原文为准；画面字幕覆盖不足时口播字幕会被主动省略。
4. **翻译**：调用当前默认对话模型，一次返回画面文字译文、口播短句译文、垂类、标题、正文、封面时间与引流标记。
5. **抹除引流**：价格、货币、折扣、优惠券、关注／点赞／订阅／私信／链接／店铺类文字按识别坐标做模糊遮罩，成片里不再出现；被抹除的内容也不进入字幕。
6. **中文字幕**：全部译文合成一条底部字幕轨，单行、无标点、字号随字数自动缩放（720 宽最大 48px），白字黑描边，位置偏下。
7. **标题正文**：按垂类规则生成（产品类带品牌、潮玩类带 IP、美妆类突出主题），标题 12~20 字、正文约 35 字，无标点、无话题标签、无 AI 套话。
8. **封面**：挑画面文字最少的干净帧，顶部叠标题与半透明底板，输出 jpg。
9. **交付**：每条一个 `<序号> 已完成` 文件夹，内含 `<标题>.mp4`、`中文字幕.srt`、`中外对照字幕.srt`、`视频封面.jpg`、`文案.txt`、`meta.json`；整批结束导出 `本地化汇总.xlsx`（「视频清单」＋「原文对照」两张表）。

## 使用

1. 左侧栏点「视频本地化」。
2. 粘贴链接（每行一个，分享文本和本地路径都可以），按需填写输出目录。
3. 点「开始处理」。**链接严格按输入顺序逐条处理**，面板显示每条视频的阶段（获取／识别／翻译／合成／待归档）、进度与失败原因；「停止」立即中断当前批次。
4. 整批跑完后统一归档：按序号先建 `1 已完成`、`2 已完成`… 文件夹，再按顺序把成片改成中文标题放进对应文件夹（因此文件夹序号永远等于链接顺序）。
5. 最后生成汇总表，用「在访达打开」查看输出目录或 Excel。

## 运行环境

- 随包自带 `runtime/bin` 下的 ffmpeg 与 OCR 二进制、Noto Sans SC 字体、`runtime/pylib` 的 faster-whisper 运行库与 `tiny` 模型。
- 链接下载优先用 `yt-dlp`：会查 PATH、`~/Downloads/.venv/bin/yt-dlp`、Homebrew 路径，也可用 `ytdlpPath` 指定；缺 yt-dlp 时降级 tikwm。
- 代理：`proxy` 留空时自动探测 `127.0.0.1:7890`（FlClash 等 Clash 系默认端口）。
- 需要 `python3`（系统自带即可）。
- TikTok 解析接口在部分网络环境不可达；失败会以单条错误呈现，不影响同批其它视频。可在插件配置里给 `proxy` 填 HTTP 代理。

## 配置项（`cordis.patch.yml` 的 `config`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `outputRoot` | `~/Downloads/海外视频本地化` | 批次根目录，每次运行新建 `批次-时间戳` 子目录 |
| `concurrency` | `2` | 同时处理的视频数（1–4） |
| `asrModel` | `small` | faster-whisper 模型名或本地模型目录。本机已内置 `tiny`；配置的模型未下载时自动用 `tiny`（面板日志会注明） |
| `ocrLangs` | `ja-JP,ko-KR,en-US` | Vision OCR 识别语言 |
| `fps` | `4` | 抽帧频率 |
| `maxCharsPerLine` | `26` | 单条字幕字数上限 |
| `provider` / `model` | 空 | 翻译用模型；留空跟随当前默认模型 |
| `proxy` | 空 | 下载代理。留空自动探测 `127.0.0.1:7890` |
| `downloaders` | `ytdlp,tikwm` | 下载顺序，逗号分隔（仅支持 ytdlp / tikwm） |
| `ytdlpPath` | 空 | 指定 yt-dlp 可执行文件 |
| `python` / `ffmpegPath` / `ocrPath` | 空 | 覆盖自带可执行文件 |
| `retainWork` | `false` | 保留中间产物（帧、音频、识别结果） |

## 已知限制

- 翻译、标题与引流判断依赖对话模型输出 JSON；模型不可用时该条会失败并在面板显示原因。
- 语音识别走 CPU：内置 `tiny` 可离线使用，`base`/`small` 需要先联网下载到 `runtime/models`（走 hf-mirror），未下载时自动回退 `tiny`。
- 引流遮罩基于识别到的文字坐标，画面中纯图形型水印不会被自动抹除。
- 下载依赖本机网络与代理：TikTok 抽取偶发失败时会自动重试并降级到 tikwm；两者都不通时该条报错，不影响同批其它视频。
- 只支持 macOS（Vision OCR 与自带的 arm64 ffmpeg）。
